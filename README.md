 ESG Analysis of UK FinTech Firms

## Project Overview

This repository showcases my contribution to a collaborative academic project investigating the relationship between Environmental, Social and Governance (ESG) performance and the valuation of UK FinTech firms.

## My Contribution

- Cleaned and organised financial datasets using Microsoft Excel.
- Used VLOOKUP, HLOOKUP and INDEX-MATCH for data validation and organisation.
- Performed multiple linear regression using the Excel Data Analysis ToolPak.
- Generated and interpreted:
  - Regression Summary
  - ANOVA Table
  - Line Fit Plots
  - Residual Plots
- Analysed:
  - Return on Assets (ROA)
  - Leverage
  - R&D Expenditure
  - Environmental, Social and Governance (ESG) Scores
  - Tobin's Q
- Produced charts and statistical outputs to support financial analysis.
